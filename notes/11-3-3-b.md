# [[11,3,3]] — graft reduction to an [[11,3,3]] CSS code

## Direction & hypothesis

Targeted the weight-6 x unrestricted cell with a smaller-n representative: the existing [[11,3,3]] entry and several larger-n siblings share parameters, so a graft that removes a qubit while preserving k, d, and weight class is a frontier extension on the n axis.

## What was searched

A single candidate produced by an unreleased code calculus tool using the E-GRAFT technique (grafting a qubit away via a low-weight element of the stabilizer row space). The resulting check matrices were screened for CSS commutativity, k, max check weight, and distance on both sides.

## Evidence trail

Distance confirmation ladder (trials per side -> lightest logical found):

| budget (trials/side) | lightest logical |
| ---: | ---: |
| exhaustive (all subsets) | 3 |
| 2,940 RIS (fresh seed) | 3 |

The submitted witnesses reproduce the bound: X: d <= 3 (upper_bound), Z: d <= 3 (upper_bound). Both sides were also checked exhaustively over all qubit subsets of size < 3; none is a logical, so d = 3 exactly for this code.

## Dead ends

None recorded for this candidate beyond the standard screening rejections (commutativity / k / weight).
